# NutriPlan 2

App de nutrición coach–cliente de **Cayetano Camuñas Coach**. El cliente registra lo que come en segundos y sigue su plan; el coach ve la evolución de todos sus clientes en un panel.

- `app/`: la app nueva (React + TypeScript + Vite, PWA). Ver `CLAUDE.md`.
- `legacy/`: la versión clásica, que sigue disponible en `/clasica`.

```bash
cd app
npm install
npm run dev        # desarrollo
npm run test:e2e   # pruebas con Supabase simulado
```
