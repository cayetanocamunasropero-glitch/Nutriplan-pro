## No instaladas (a propósito)
- `vercel-deploy` (claude-webkit): sube el código a un servicio externo (`codex-deploy-skills.vercel.sh`). Para desplegar se usa el conector/plugin oficial de Vercel.
- `deep-research` (claude-webkit): duplica la skill integrada `deep-research` y pide sustituir toda búsqueda web.
- Copias de claude-webkit de skills ya instaladas desde su repositorio original (Emil Kowalski, UI/UX Pro Max).

## Requisitos externos
- `impeccable`: descarga su motor desde las *releases* de GitHub (verificado con `engine-checksums.txt`).
- `scroll-world`: necesita Higgsfield (créditos de pago).
- `refero-design`: funciona mejor con el MCP de Refero (cuenta en refero.design).
- `design` (logos/CIP): usa APIs de generación de imágenes con clave propia.
- `chrome-bridge-automation`: necesita Chrome local con la extensión Midscene (no funciona en sesiones en la nube).
